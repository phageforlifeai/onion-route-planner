Daily routine (2 minutes)

  1. Today's plan → Add all regulars (or Import Excel), adjust quantities, remove customers with no order.
  2. Set the date / departure, press ⚡ Optimise routes.
  3. For each vehicle: Copy for WhatsApp → send to the driver, or Open in Google Maps for turn-by-turn navigation. ⬇ Excel gives printable route sheets.

What the planner optimises

  • Assigns orders to vehicles and sequences stops to minimise total driving time (or km) while respecting vehicle capacity, customer time windows, unloading time and maximum route duration.
  • If demand exceeds fleet capacity, or a customer opens late, it plans a second trip (reload at the depot).
  • It picks the latest departure for each vehicle that avoids waiting at customers.
  • Strategies: Lowest total km/time – cheapest overall; Fewest vehicles – keep a vehicle free; Balanced – equalise work between drivers.

Traffic data

  • Free (default): OpenStreetMap road distances × an editable hour-by-hour Chennai congestion profile.
  • Google historic traffic: create a key at console.cloud.google.com → APIs & Services → Credentials, enable Distance Matrix API and Geocoding API, paste it in Settings. Travel times for every customer pair are cached for 45 days, so with a stable customer base daily API usage is minimal.

Tips

  • Most accurate customer locations: open Google Maps on your phone → long-press the shop → Share → paste the link into the address box.
  • Leave time windows blank for "any time". Use Service min for slow-unloading customers.
  • Everything is stored in the data/ folder – copy it to back up.
